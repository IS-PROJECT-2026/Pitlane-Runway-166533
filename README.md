# ✈️ Pit Lane & Runway 🏎️

> **How aviation and motorsport actually work — one system at a time.**

**Pit Lane & Runway** is an educational web project that explores the systems, technology, and concepts behind **aviation** and **Formula 1**.

The project presents technical information in a more engaging and accessible way by treating aviation and motorsport as interconnected worlds of engineering, systems, people, and technology.

---

## 📌 Project Overview

Aviation and Formula 1 may appear to be completely different industries, but both depend on highly engineered systems working together under demanding conditions.

**Pit Lane & Runway** explains these systems through concise educational content, visual explanations, interactive elements, and structured topic pages.

The website is designed for users who are curious about **how things work**, rather than simply wanting facts about aircraft or racing.

### Project Domains

* ✈️ **Aviation**
* 🏎️ **Formula 1 / Motorsport**

### Project Tagline

> *How aviation and motorsport actually work — one system at a time.*

---

## 🎯 Objectives

The project aims to:

1. Create an educational website focused on aviation and motorsport systems.
2. Explain technical concepts in a simple and approachable manner.
3. Organise information into reusable topic-based pages.
4. Use interactive elements to make learning more engaging.
5. Demonstrate effective HTML, CSS, and JavaScript development.
6. Apply responsive and accessible web design principles.
7. Demonstrate collaborative development using Git and GitHub.
8. Follow a structured feature-branch and pull-request workflow.

---

## ✨ Key Features

### 🏠 Homepage

The homepage introduces **Pit Lane & Runway**, its two subject areas, and the type of educational content available on the site.

---

### ✈️ Aviation Topics

The Aviation section explains systems and concepts associated with aircraft and aviation.

Topics can cover areas such as:

* How Planes are cleared for takeoff

---

### 🏎️ Formula 1 Topics

The Formula 1 section explores the systems and engineering behind modern motorsport.

Topics can cover areas such as:

* How F1 Aerodynamics work
* Meet The Grid

---

### 📚 Topic Index

Topics are organised into structured indexes so that users can easily discover and navigate educational content.

The same underlying structure can be reused across Aviation and Formula 1 content.

---

### 🧩 Interactive Explanations

The website incorporates interactive elements to help users understand technical concepts rather than simply reading static text.

Examples include:

* Interactive diagrams
* Expandable explanations
* Visual system breakdowns
* Interactive learning elements

---

### 📖 Glossary

A glossary provides explanations for technical terminology used throughout the website.

This allows users who are unfamiliar with aviation or motorsport terminology to understand the content more easily.

---

### 🧠 Quizzes

Quiz-based elements provide an opportunity for users to test their understanding of concepts introduced throughout the website.

---

## 🎨 Design & Branding

The visual identity combines elements inspired by **aviation**, **motorsport**, and technical engineering.

The design uses a dark, dramatic aesthetic while maintaining readability and accessibility.

### Colour Palette

| Colour        | Hex       | Purpose                        |
| ------------- | --------- | ------------------------------ |
| Dark Ruby     | `#70000E` | Primary F1-inspired accent     |
| Neon Navy     | `#131936` | Aviation/technical foundation  |
| Bleached Sand | `#E3D7BF` | Supporting neutral             |
| White         | `#FFFFFF` | Light backgrounds and contrast |
| Black         | `#000000` | Primary text                   |

The colour palette is implemented through reusable CSS variables to maintain consistency throughout the website.
